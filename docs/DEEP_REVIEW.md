## 配置入口

- `app.config.json`：appId、productName，同步用于主进程与打包器。
- `.env.example`：公开 API 基址、下载 origin、更新地址与发布身份说明。私钥、密码、访问令牌不能放进公开配置。
- `src/shared/config.js`：配置白名单、URL 与窗口尺寸校验。
- `electron-builder.cjs`：平台图标、目标架构、安装方式、签名及更新发布元数据。
- `.github/workflows/desktop.yml`：macOS / Windows 验证与目录打包，远端执行情况见 [GitHub Actions](https://github.com/wn228664/desktop-app-framework/actions/workflows/desktop.yml)。

开发可显式使用本机 HTTP API，生产 API 只接受 HTTPS。下载白名单必须是 origin，不能附路径。更新地址不能带查询参数，启用更新时必须配置发布者，并具备对应平台真实签名身份。默认本地包无发布服务、无自动签名、无自动发布。
