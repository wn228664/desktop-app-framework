# 注释范围

手写 main、preload、renderer、shared、测试和构建脚本的绑定、参数、回调、类及私有字段均在源码说明。主进程公开实例属性在首次赋值处说明，组件 props 紧邻字段说明，模板局部变量和回调在模板契约中说明。样式自定义属性标注用途，已有滚动与响应式规则保留原契约。

`app.config.json` 是运行和 builder 共用的公开应用标识；`package.json` 描述脚本与依赖，锁文件固定安装结果。这些 JSON 由工具直接解析，不插入注释。`resources/entitlements.mac.plist` 表达签名权限；修改前需重新验证对应平台打包。生成的第三方许可保留原文，不添加逐行中文，收集器本身属于注释范围。

`out`、`release`、依赖、测试报告与截图是生成内容；图标等二进制资源不人工注释。真实 macOS 运行、Windows 安装、系统凭据、签名更新和真实服务接入是不同验收项，不能由本地替身测试互相替代。
