# 架构与扩展

## 进程边界

```text
Vue 页面 / 通用组件
    ↓ renderer/core/desktop.js：信封解包、取消绑定
contextBridge：固定方法、固定事件、监听解绑
    ↓ IPC：主窗口 + 主框架 + 精确文档校验
main：参数校验、权限、任务归属、原生交互
    ↓
文件授权 / HTTP / 配置 / 系统加密 / 安装更新
```

renderer 不导入 Electron、Node、文件系统或主进程服务。preload 只引用 Electron，构建成单一 CommonJS 文件供沙盒使用。shared 只包含与运行环境无关的错误和校验。

`app.config.json` 是应用名与 appId 的共同来源，避免打包身份与 Windows 运行时身份分离。环境配置经过明确白名单与 URL 校验后才编译，未知 DESKTOP_ 字段不会进入产物。

`src/main/index.js` 负责组合和生命周期；可独立测试的存储、文件、请求、任务和凭据放在 services 中。没有为演示引入登录、权限、动态业务模块或插件容器。

## 安全约束

- `sandbox: true`、`contextIsolation: true`、`nodeIntegration: false`、`webSecurity: true`。
- 每个 IPC 都校验调用窗口、主框架和精确文档 URL。Hash 路由变化允许；外部文档和 iframe 不允许。
- 禁止 `window.open`、意外页面导航、webview 附加和浏览器权限请求。
- CSP 不允许外部脚本、框架文档、对象或表单跳转。开发服务只监听本机地址。
- 生产 HTML 会移除本机 WebSocket 开发例外，renderer 的系统和网络能力继续通过桌面桥访问。
- 外部链接只接受 HTTPS，显示域名及完整 URL 并由用户确认。不会使用任意 `shell` 命令。
- 文件访问用窗口绑定的授权 ID，不提供 `readFile(path)` 或任意目录访问。授权不是持久化路径书签，窗口关闭即失效。
- 请求固定 API 基址，拒绝重定向和基址范围外的路径。下载独立 origin 白名单，不附加 API 令牌。
- 捕获到的底层异常不携带路径、令牌、请求体或堆栈跨越 IPC。主进程日志只写时间与公开错误代号。

这些约束降低权限暴露，不代表可把任意不可信 HTML 加载到应用主文档。远程内容应在独立受限窗口/浏览器中展示，并重新设计权限边界。

## 异步与生命周期

`createAsyncAction()` 管理一个动作：同步上锁、重复调用复用 Promise、取消后立即解锁、旧结果失效。Vue 版本 `useAsyncAction()` 在作用域销毁时取消。

调用方的 operation 需使用 `signal`，尤其要在等待后、写入 UI 或提交副作用前检查。控制器可以拦截迟到结果，但无法回滚服务端已经发生的写入。写接口不自动重试。

主进程 `Tasks` 给请求和传输附加超时、取消和窗口归属，最多 8 个并行任务、50 条完成历史。历史只在内存中，不存响应或请求内容。

事件订阅返回取消函数；组件在 `onScopeDispose` 中调用。窗口销毁撤销该窗口全部文件授权与进行中任务。主进程权限事件和更新监听属于应用生命周期，注册一次。

## 状态所有权

- 表单草稿由调用方持有；通用表单只 emit 新对象，不修改 props。
- 搜索输入与已提交条件分开，按搜索/重置才改变表格查询。
- DataTable 持有分页/排序/选择；loader 只负责按契约获取数据。
- Pinia 只管理跨页偏好与任务。配置以主进程成功持久化的结果为准。
- 凭据不放进 Pinia、localStorage、URL 或日志，设置后从输入框清除。

## 布局与适配

外壳为固定高度 flex，所有可收缩区域设置 `min-height: 0` / `min-width: 0`。根节点禁止滚动。`FrameworkPage` 默认只有内容区滚动；表格页使用 `scroll=false`，滚动交给表格。

侧栏在窄宽度折叠为图标；双栏卡片变单栏；设置行重排。短窗口减少顶部留白。缩放使用 Electron 的 zoom factor，CSS 以缩放后的逻辑宽度布局。长表格保留横向滚动与省略提示，不强行压缩到不可读。

原生标题栏保留 macOS 窗口按钮和 Windows 系统窗口行为。最小窗口基准为 760×540，屏幕工作区更小时按工作区限制；窗口恢复会夹取到当前显示器可见范围。没有未经验证的自绘标题栏或拖拽区域。

## 扩展步骤

新增页面只需添加路由及本模块组件。新增特权能力依次补充主进程输入契约、固定 IPC、preload 方法、renderer 封装与关键边界测试。不要把业务 API 塞进 shared，也不要让通用组件直接决定业务成功条件。
